# Fixed Shaker Disturbance

This file is the single reference description for the fixed shaker-side test disturbance used by:

- `tune_parameter`
- `shaker_disturbance`
- `actuator_disturbance`
- `actuator_disturbance_sweep`

The waveform is generated by `utils.fixed_disturbance.fixed_shaker_disturbance`.

## Parameters

- Seed: `20260516`
- Duration: `9.0 s`
- Sample time: `0.03 s`
- Samples: `301`, including `t = 0.00 s` and `t = 9.00 s`
- Shaker voltage limit: `[-3, 3] V`
- Shaker force limit: `[-9, 9] N`
- Conversion: `force_N = 3 * voltage_V`
- Frequency band: `0.70-5.00 Hz`
- Target peak force: `0.92 * 9 N = 8.28 N`

## Construction

Let `d_raw(t)` be a deterministic, higher-amplitude waveform generated from the seed above:

```text
d_raw(t) =
  A_mod(t) * (
    0.58 * multisine_fixed(t)
    + 0.28 * up_chirp(t)
    + 0.22 * down_chirp(t)
  )
```

Component definitions:

- `multisine_fixed`: six fixed tones at `0.75, 1.25, 1.85, 2.65, 3.55, 4.65 Hz` with weights `0.35, 0.50, 0.65, 0.60, 0.45, 0.30`; phases are generated by seed `20260516`.
- `up_chirp`: unit chirp from `0.70 Hz` to `5.00 Hz`; phase is generated by seed `20260516`.
- `down_chirp`: unit chirp from `5.00 Hz` to `0.70 Hz`; phase is generated by seed `20260516`.
- `A_mod(t)`: slow amplitude modulation `1 + 0.18 * sin(2*pi*0.35*t + phase)`.

After summation, a raised-cosine start/stop envelope is applied:

- Ramp duration: `min(0.6 s, 0.12 * duration) = 0.6 s`
- The first sample is forced to exactly `0 N`.
- The last sample is forced to exactly `0 N`.
- The signal enters and exits smoothly, avoiding a hard shaker step at trajectory boundaries.

Finally, the waveform is uniformly scaled to a target peak of `8.28 N` and clipped to the shaker force limit `[-9, 9] N`.

## CSV Copies

The same generated waveform is saved into several experiment directories for convenience:

- `tune_parameter/data/fixed_shaker_disturbance.csv`
- `shaker_disturbance/data/fixed_test_disturbance.csv`
- `actuator_disturbance/data/fixed_test_disturbance.csv`
- `actuator_disturbance_sweep/data/fixed_test_disturbance.csv`

These files should be regenerated together whenever the waveform definition changes.
